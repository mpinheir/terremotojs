About This App

This application displays significant earthquakes that have occurred worldwide in the past 30 days, using data from the USGS Earthquake Hazards Program. The app was created as an educational project to demonstrate JavaScript, API integration, and web development skills.

Created by Marcelo Pinheiro as part of the OsProgramadores.com community, this open-source project is available on GitHub for learning and collaboration.
